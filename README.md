🌦️ CSC380 Weather Application

An open-source weather application that provides real-time weather data using the OpenWeather API. Developed as part of CSC380 to demonstrate API integration, data handling, and user-focused design.

📌 Overview

This application allows users to retrieve current weather conditions for any city using live data from the OpenWeather API. The goal is to deliver a simple, responsive, and clean user experience while showcasing practical software development skills.

🚀 Features
🌍 Search weather by city name
🌡️ Displays temperature and weather conditions
☁️ Real-time data from OpenWeather API
⚡ Lightweight and fast
🧩 Modular and easy-to-extend codebase

🔑 API Setup

This project uses the OpenWeather API.

Steps to get your API key:
Go to https://openweathermap.org/
Create an account
Generate an API key
Insert your key into the project where indicated

⚙️ Installation & Setup
1. Clone the repository

git clone https://github.com/schickla/CSC380.Project.git

2. Navigate into the project

cd CSC380.Project

3. Add your API key

Locate the configuration file or source code section where the API key is required and insert your key.

4. Run the application
